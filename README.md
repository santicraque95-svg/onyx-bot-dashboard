# Onyx e-Sports — Bot Dashboard

1. Instala Node.js.
2. Abre esta pasta no terminal.
3. Executa `npm install`.
4. Copia `.env.example` para `.env`.
5. Coloca o `CLIENT_ID` do bot no `.env`.
6. Executa `npm start`.
7. Abre `http://localhost:3000`.

O botão de convite é gerado automaticamente pelo Client ID.
